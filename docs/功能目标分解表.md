# 攻击演示系统 - 功能目标分解表

## 1. 系统概述

本系统是一个基于B/S架构的网络攻击演示平台，用于教学和学习网络安全知识。系统专注于SSRF（服务器端请求伪造）攻击的演示、攻击代码分析和防御方法介绍。

## 5. SSRF攻击演示功能详情

### 5.1 攻击动画演示
- 展示攻击者 → Web服务器 → 内网服务的请求流程
- 可视化三个攻击阶段：探测内网、读取文件、攻击服务
- 实时统计面板显示攻击请求数、发现的服务、读取的文件等

### 5.2 交互式演示
- 支持输入自定义URL
- 预设多种测试URL（Redis、MySQL、内网Web、本地文件等）
- 模拟不同URL的响应结果

### 5.3 攻击场景
- 探测内网Redis服务 (http://127.0.0.1:6379)
- 探测内网MySQL服务 (http://127.0.0.1:3306)
- 读取本地文件 (file:///etc/passwd)
- 访问内网管理界面 (http://192.168.x.x)

## 6. 防御技术要点

### 6.1 URL白名单验证
- 只允许访问预定义的可信域名
- 验证域名解析后的IP地址

### 6.2 协议限制
- 只允许http/https协议
- 禁止file://、dict://、gopher://等危险协议

### 6.3 DNS重绑定防护
- 多次DNS解析并比较结果
- 使用已验证的IP发起请求

### 6.4 请求限制
- 设置合理的超时时间
- 限制响应大小
- 禁用重定向跟随
