# 入侵防御技术及应用课程设计报告

## 攻击演示系统设计与实现

---

## 一、课程设计目的

本课程设计旨在设计并实现一个基于B/S架构的攻击演示系统，通过该系统：

1. 帮助新手用户了解SSRF（服务器端请求伪造）攻击的原理和步骤
2. 演示SSRF攻击的具体实现方法和效果
3. 分析攻击代码，理解漏洞成因
4. 介绍和展示相应的防御方法
5. 提高网络安全意识和防护能力

## 二、系统需求分析

### 2.1 功能需求

系统需要实现以下核心功能：

1. **界面功能**：可配置、可显示系统运行结果
2. **攻击演示功能**：
   - SSRF攻击原理介绍
   - SSRF攻击动画演示（悬浮窗动画，与攻击场景联动）

   - 模拟内网服务攻击（Redis、MySQL、Elasticsearch、管理后台）
   - 服务器文件读取（/etc/passwd、/proc/self/environ等）

3. **防御功能**：

### 2.2 攻击类型选择

本系统专注于SSRF（服务器端请求伪造）攻击演示，选择理由：

1. **高危漏洞**：SSRF在OWASP Top 10中排名靠前
2. **攻击面广**：可探测内网、读取文件、攻击内网服务
3. **难度较高**：属于Hard级别攻击，适合深入学习
4. **防御复杂**：需要多层防御策略

### 2.3 SSRF攻击原理

SSRF（Server-Side Request Forgery）是一种由攻击者构造请求，由服务端发起请求的安全漏洞。攻击者可以利用SSRF漏洞：

- **探测内网服务**：访问内网的Redis、MySQL、MongoDB等服务
- **读取本地文件**：通过file://协议读取服务器上的敏感文件
- **攻击内网服务**：利用内网服务的漏洞进行攻击
- **端口扫描**：扫描内网主机的开放端口

### 2.4 非功能需求

1. **可用性**：界面友好，操作简单
2. **可维护性**：代码结构清晰，注释完整
3. **安全性**：仅用于教学演示，不影响真实系统
4. **兼容性**：支持主流浏览器访问

### 4.2 核心代码实现

#### 4.2.1 SSRF漏洞API（支持防御模式）

```python
@app.route('/ssrf/fetch')
def ssrf_fetch():
    """SSRF漏洞API - 支持防御模式演示"""
    url = request.args.get('url', '')
    defense_mode = request.args.get('defense', 'true').lower() == 'true'

    try:
        from urllib.parse import urlparse
        parsed = urlparse(url)

        # 防御模式：URL安全检查
        if defense_mode:
            # 1. 协议白名单检查
            allowed_protocols = ['http', 'https']
            if parsed.scheme and parsed.scheme not in allowed_protocols:
                return jsonify({
                    'success': False,
                    'error': f'🛡️ 防御拦截: 协议 "{parsed.scheme}" 不在白名单中',
                    'defense': True, 'rule': '协议白名单'
                })

            # 2. 内网地址检查
            if parsed.hostname in ['127.0.0.1', 'localhost', '0.0.0.0']:
                return jsonify({
                    'success': False,
                    'error': f'🛡️ 防御拦截: 禁止访问内网地址 {parsed.hostname}',
                    'defense': True, 'rule': '内网地址过滤'
                })

            # 3. 内网IP段检查
            if parsed.hostname:
                ip_parts = parsed.hostname.split('.')
                if len(ip_parts) == 4:
                    first = int(ip_parts[0])
                    second = int(ip_parts[1])
                    if first == 10 or (first == 172 and 16 <= second <= 31) or \
                       (first == 192 and second == 168):
                        return jsonify({
                            'success': False,
                            'error': f'🛡️ 防御拦截: 禁止访问内网IP段',
                            'defense': True, 'rule': '内网IP段过滤'
                        })

            # 4. 关键词检查
            ssrf_keywords = ['internal', 'admin', 'redis', 'mysql', 'elasticsearch']
            for keyword in ssrf_keywords:
                if keyword in (parsed.path or '').lower():
                    return jsonify({
                        'success': False,
                        'error': f'🛡️ 防御拦截: URL包含敏感关键词 "{keyword}"',
                        'defense': True, 'rule': '关键词过滤'
                    })

        # 处理file://协议
        if parsed.scheme == 'file':
            file_path = parsed.path
            with open(file_path, 'r', encoding='utf-8', errors='ignore') as f:
                content = f.read(5000)
            return jsonify({'success': True, 'content': content})

        # 处理内网请求（使用Flask test_client）
        if parsed.hostname in ('127.0.0.1', 'localhost'):
            with app.test_client() as client:
                resp = client.get(parsed.path or '/')
                return jsonify({
                    'success': True,
                    'content': resp.get_data(as_text=True)[:5000]
                })

        # 外部URL请求
        import urllib.request
        response = urllib.request.urlopen(url, timeout=5)
        content = response.read().decode('utf-8', errors='ignore')
        return jsonify({'success': True, 'content': content[:5000]})

    except Exception as e:
        return jsonify({'success': False, 'error': str(e)})
```

#### 4.2.3 访问密码验证

```python
@app.before_request
def check_password():
    """检查访问密码"""
    if not ACCESS_PASSWORD:
        return

    # 不需要验证的路径
    skip_paths = ['/login', '/static/']
    for path in skip_paths:
        if request.path.startswith(path):
            return

    # 检查cookie中的密码哈希
    password_hash = request.cookies.get('access_token')
    if password_hash == get_password_hash(ACCESS_PASSWORD):
        return

    # 未验证则跳转到登录页
    if request.path != '/login':
        return redirect(url_for('login'))

@app.route('/login', methods=['GET', 'POST'])
def login():
    """登录页面"""
    client_ip = request.remote_addr

    # 检查IP是否被锁定
    if is_ip_locked(client_ip):
        error = f'登录失败次数过多，请稍后再试'
        return render_template('login.html', error=error)

    if request.method == 'POST':
        password = request.form.get('password', '')
        if password == ACCESS_PASSWORD:
            resp = redirect(url_for('index'))
            resp.set_cookie('access_token', get_password_hash(password),
                          max_age=86400, httponly=True, samesite='Strict')
            return resp
        else:
            record_failed_attempt(client_ip)
            error = f'密码错误，还剩 {MAX_ATTEMPTS - login_attempts[client_ip]["count"]} 次机会'

    return render_template('login.html', error=error)
```
