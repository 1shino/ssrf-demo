# 入侵防御技术及应用课程设计报告

## 攻击演示系统设计与实现

---

## 一、课程设计目的

本课程设计旨在设计并实现一个基于B/S架构的攻击演示系统，通过该系统：

1. 帮助新手用户了解SSRF（服务器端请求伪造）攻击的原理和步骤
2. 演示SSRF攻击的具体实现方法和效果
3. 分析攻击代码，理解漏洞成因
4. 介绍和展示相应的防御方法
5. 提高网络安全意识和防护能力

## 二、系统需求分析

### 2.1 功能需求

系统需要实现以下核心功能：

1. **界面功能**：可配置、可显示系统运行结果
2. **攻击演示功能**：
   - SSRF攻击原理介绍
   - SSRF攻击动画演示
   - SSRF交互式攻击演示
   - 攻击代码分析
   - 防御方法介绍与展示
3. **用户体验**：便于用户观看的攻击演示效果，易于操作

### 2.2 攻击类型选择

本系统专注于SSRF（服务器端请求伪造）攻击演示，选择理由：

1. **高危漏洞**：SSRF在OWASP Top 10中排名靠前
2. **攻击面广**：可探测内网、读取文件、攻击内网服务
3. **难度较高**：属于Hard级别攻击，适合深入学习
4. **防御复杂**：需要多层防御策略

### 2.3 SSRF攻击原理

SSRF（Server-Side Request Forgery）是一种由攻击者构造请求，由服务端发起请求的安全漏洞。攻击者可以利用SSRF漏洞：

- **探测内网服务**：访问内网的Redis、MySQL、MongoDB等服务
- **读取本地文件**：通过file://协议读取服务器上的敏感文件
- **攻击内网服务**：利用内网服务的漏洞进行攻击
- **端口扫描**：扫描内网主机的开放端口

### 2.4 非功能需求

1. **可用性**：界面友好，操作简单
2. **可维护性**：代码结构清晰，注释完整
3. **安全性**：仅用于教学演示，不影响真实系统
4. **兼容性**：支持主流浏览器访问

系统包含以下功能模块：

1. **主界面模块**：系统首页、导航菜单

   - 攻击原理介绍
   - 攻击动画演示（Canvas动画）
   - 交互式URL测试
   - 攻击代码分析
3. **防御方法模块**：SSRF防御方案详解

### 3.4 SSRF攻击演示设计

#### 动画演示
- **攻击者节点**：表示发起攻击的用户
- **Web服务器**：存在SSRF漏洞的目标服务器
- **内网服务**：Redis、MySQL、内网Web、MongoDB等
- **文件系统**：服务器本地文件

动画展示三个攻击阶段：
1. **探测阶段**：通过SSRF探测内网服务
2. **读取阶段**：利用file://协议读取敏感文件
3. **攻击阶段**：利用SSRF攻击内网服务

#### 交互式演示
- 输入框支持自定义URL
- 预设多种测试URL：
  - Redis服务 (http://127.0.0.1:6379)
  - MySQL服务 (http://127.0.0.1:3306)
  - 内网Web (http://192.168.1.1:80)
  - 读取passwd (file:///etc/passwd)
  - 读取Windows hosts (file:///C:/Windows/System32/drivers/etc/hosts)

### 4.2 核心代码实现

#### 4.2.1 Flask后端路由

```python
@app.route('/ssrf')
def ssrf_demo():
    """SSRF攻击演示页面"""
    return render_template('ssrf.html')

@app.route('/ssrf/fetch')
def ssrf_fetch():
    """SSRF漏洞API - 故意不验证URL（演示漏洞）"""
    url = request.args.get('url', '')

    # 故意不做URL验证（演示漏洞）
    try:
        import urllib.request
        response = urllib.request.urlopen(url, timeout=5)
        content = response.read().decode('utf-8', errors='ignore')
        return jsonify({'success': True, 'content': content})
    except Exception as e:
        return jsonify({'success': False, 'error': str(e)})
```

#### 4.2.2 Canvas动画实现

```javascript
// 动画主循环
function animate() {
    if (!isRunning) return;

    animationFrame++;
    ctx.clearRect(0, 0, canvas.width, canvas.height);

    drawBackground();
    drawNode(nodes.attacker);
    drawNode(nodes.server);
    nodes.internal.forEach(node => drawNode(node, 20));

    // 根据攻击阶段生成请求
    if (attackPhase === 1 && animationFrame % 60 === 0) {
        // 探测内网服务
        const target = nodes.internal[Math.floor(Math.random() * nodes.internal.length)];
        attackRequests.push(createRequest('probe', nodes.attacker, nodes.server, '#ff4444', 'SSRF'));
        attackRequests.push(createRequest('probe', nodes.server, target, '#00ccff', '请求'));
    }

    drawRequests();
    animationId = requestAnimationFrame(animate);
}
```
